🎯 Number Guessing Game

A simple Number Guessing Game developed using Python.

In this game, the computer randomly selects a number, and the player has to guess the correct number within a limited number of attempts.

🎮 Difficulty Levels

The game has three difficulty levels:

Difficulty| Number Range| Maximum Attempts
Easy| 1 - 50| 10
Medium| 1 - 100| 10
Hard| 1 - 1000| 10

✨ Features

- Three difficulty levels: Easy, Medium, and Hard
- Random number generation
- Maximum 10 attempts
- Shows whether the guess is too high or too low
- Displays a congratulation message when the correct number is guessed
- Displays the correct number when all attempts are used
- Simple and beginner-friendly interface

🛠️ Technologies Used

- Python
- Random Module

▶️ How to Run

Step 1: Install Python

Make sure Python is installed on your computer.

Step 2: Download the Project

Download or clone this repository from GitHub.

Step 3: Open the Project

Open the project folder in VS Code or any Python-supported editor.

Step 4: Run the Program

Open the terminal and run:

python number_guessing_game.py

🎯 How the Game Works

1. Start the program.
2. Choose a difficulty level:
   - "1" → Easy
   - "2" → Medium
   - "3" → Hard
3. The computer randomly generates a secret number.
4. Enter your guess.
5. The game gives a hint:
   - Too Low → Your guess is smaller than the secret number.
   - Too High → Your guess is larger than the secret number.
6. Continue guessing until:
   - You guess the correct number, or
   - You use all 10 attempts.
